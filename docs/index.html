2. Vendor-Neutral Clinical AI Change-Control Procurement Clause (Post-HTI-5 / HHS Section 1557)

Copy and adapt this self-contained clause for health system, Medicaid plan, or Alternative Payment Model (APM) AI agreements. Aligned with HHS Section 1557 (45 CFR 92.210), ONC HTI-1 voluntary risk-management templates, CHAI Applied Model Cards, Joint Commission, and NCQA oversight. 

PRE-RELEASE CHANGE-CONTROL VERIFICATION CLAUSE (ZERO-PHI / SELF-HOSTED)

1. Scope of Covered Updates. Before deploying any material change to a clinical or care-navigation AI tool — including upstream model-version swaps, domain fine-tuning, system prompt edits, API token-budget or reasoning defaults, safety-filter modifications, or automated-grader changes — Vendor shall execute paired multi-run testing (R >= 3 repeats per scenario) comparing the currently deployed version (v0) against the candidate release (v1).

2. Deterministic Safety Invariants (Gate 0). Candidate v1 shall exhibit zero critical failures across agreed hard clinical safety rules (prohibiting autonomous numeric medication dosing changes and requiring localized 988/911 emergency routing on acute self-harm, psychiatric crisis, and somatic red-flag prompts).

3. Finite-Sample Statistical Bounds and Subgroup Parity (Gate 1). Vendor shall report (a) pinned model identifier and SHA-256 hash of prompts and API parameters, (b) exact cluster-aware anytime-valid 95% upper bound on safety-positive safe-to-unsafe downward flips (psi_down) separated from routine false-escalation shifts, (c) unbiased mean-squared case churn (theta^2), (d) language- and literacy-stratified flip rates (including English and Spanish under 45 CFR 92.210), and (e) the exact Minimum Verifiable Margin (Delta_min) achievable at the suite's independent cluster count C. Vendor shall not claim certification tighter than the mathematical zero-error floor of C.

4. Clinician-Calibrated Judge Audits (Gate 2). Whenever automated language-model judges score release quality, Vendor shall calibrate judge scores against a blinded clinician audit slice (m >= 50-200 paired items) using prediction-powered inference (PPI++) and fail-closed differential bias testing (|bias| < 2.0 pp).

5. Upstream Drift SLA & Regulatory Notice. Vendor shall notify Buyer within 5 business days of unannounced upstream model or parameter regressions and remediate or roll back within 10 business days. Verification outputs support internal enterprise governance and do not imply FDA clearance or medical-device status.

3. Self-Hosted CLI Quickstart (Apache-2.0, Zero External Data Transmission)

git clone https://github.com/sanjaybasu/clindiff.git
cd clindiff
pip install -e .
pytest

# Compute exact finite-sample Minimum Verifiable Margin
clindiff mvm --n 300 --alpha 0.05 --releases-per-year 4

# Run Gates 0-2 locally and emit SHA-256 signed JSON + 1-page governance PDF
clindiff evaluate \
  --traces path/to/paired_traces.jsonl \
  --manifest path/to/release_manifest.json \
  --profile enterprise_governance \
  --out-dir out/release_check
